Anda adalah seorang asisten mobile dev yang akan membantu saya menyusun sistem test yang diperbolehkan menggunakan tools AI. Pertama pahami konteks yang ingin saya rancang dengan memahami isi file pdf panduan nya. Kemudian berdasarkan isinya, saya ingin anda membangunkan sebuah sistem pilihan ke 3 yaitu : LOG DURASI DAN TARIF PARKIR dari sistem dengan tech saya yaitu dengan Dart Flutter yang sudah saya set up di folder

Saya ingin ini menjadi Aplikasi pencatatan kendaraan masuk dan keluar dengan kalkulasi tarif parkir berdasarkan durasinya dengan keinginan saya yaitu Sistem parkir ini itu berlokasi atau di code nya nanti ber title Sistem parkir Ocean Mall Penajam. Untuk tampilan, saya ingin anda membuat dengan color palate warna segar yang nyaman di pandang seperti Hijau muda, putih, sedikit elemen warna laut, kemudian dengan teks warna hitam yang jelas. di ikuti tombol tampilan yang menggunakan icon yang bagus khas Flutter

Dari kodebase Dart Flutter itu saya ingin beberapa fitur : 
1. Form pencatatan masuk yang berisi plat nomor kendaraan dan pilihan jenis kendaraan (Motor atau Mobil). Nanti saya ingin anda memberi sample nya seklian agar tampil beberapa
2. Daftar parkir aktif yang menampilkan kendaraan yang sedang berada di area parkir beserta waktu masuknya dalam kurun waktu tertentu. (Disini saya ingin ada tampilan jam dan menitnya kendaraan itu)
3. Tombol pencatatan keluar pada baris kendaraan untuk memproses perhitungan biaya parkir dengan ketentuan. (Dimana jika ada kendaraan yang akan di data keluar akan melalui bagian ini)
Data tarif:
• Motor: Rp 2.000 per jam (durasi minimal dihitung satu jam).
• Mobil: Rp 5.000 per jam (durasi minimal dihitung satu jam).

4. Daftar histori kendaraan yang telah selesai diproses beserta total biaya yang dibayarkan. (Berikan secara detail kendaraan yang di proses nya seperti data plat, waktu, biaya, dll)

Batasan dan Validasi:
• Plat nomor kendaraan tidak boleh kosong.
• Plat nomor yang sama tidak dapat dicatat masuk kembali jika kendaraan tersebut masih berstatus aktif di area parkir.

Fitur Tambahan (Opsional):
• Pencarian plat nomor pada daftar parkir aktif. (serta berikan keterangan jika sudah keluar)

Beberapa fitur tambahan yang saya pribadi inginkan : 
Ada navigasi filter kategori untuk jenis kendaraan, status kendaraan, serta kategori waktu untuk menampilkan kendaraan nya
Ada data jenis kendaraan dan kategori berapa hari dia datang untuk parkir ataupun jenis pengkategorian lain untuk mendata
